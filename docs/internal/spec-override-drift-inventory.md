# Spec override drift inventory

Tracked by bead `dynamodb-efcore-provider-ar7.1`.

## Classification key

- **Safe base call**: skipped override can still delegate to upstream `base.*`; xUnit skip prevents execution but preserves intent.
- **Sync-query adapter**: upstream sync row would execute synchronous query APIs; DynamoDB provider supports async query execution only.
- **DynamoDB architectural skip**: upstream intent depends on unsupported durable DynamoDB/provider feature: joins/FKs/navigation fixup, aggregates, set ops, unsupported subquery shape, ordering guarantee, or required partition-key model shape.
- **Provider gap**: shape should be supportable eventually but translation/materialization currently fails.
- **Fixture bug**: Dynamo spec fixture/model setup, not provider feature, blocks upstream intent.
- **Provider-specific coverage split**: custom body validates narrower DynamoDB-supported behavior than upstream method name promises.
