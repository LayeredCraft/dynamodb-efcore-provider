# EF Core Specification Custom Override Audit

This matrix records executable specification-test overrides whose body does not call the inherited EF
Core base method. Use it before replacing custom bodies with thin `base` calls, `NoSyncTest` wrappers,
or centralized skips.

Decisions:

- **Keep** — local body is provider-specific infrastructure/guard behavior, not an upstream spec body
    to thin.
- **Delegate/skip** — method can become a thin base-delegating skip once companion coverage exists.
- **Move then delegate/skip** — preserve provider behavior in unit/integration tests before changing
    the spec override.
- **Needs decision** — do not refactor until coverage gap is closed or explicitly accepted.
